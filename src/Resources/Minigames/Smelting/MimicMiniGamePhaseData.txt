# Smelting bars (game_smelting.swf): the four rounds of each bar, in the movie's own MimicMiniGamePhaseData.txt
# layout (Smelting.SmeltingGameServer.OnLevelData). The server sends a bar's rows to the movie as OnPhaseDataMsg,
# one row each. Lines starting with # are for people and are never sent.
#
# ID^GAME^SEQUENCE^DURATION^OBJECTIVE_ID^START_ID^END_ID^STAGE_TYPE^DATA1^...^DATA11
#   GAME      the bar: the MiniGameData.txt id of its game (the Level of its Mimic.json entry)
#   SEQUENCE  the round, from 1; rows with the same GAME and SEQUENCE are alternatives, one picked each play
#   DURATION  seconds on the round's timer
#
# STAGE_TYPE (100 + the movie's stage) and what DATA1 on mean (the movie clamps some to the range given):
#   101 break down the ore  ore (1 Copper, 2 Tin, 3 Iron, 4 Silver, 5 Gold), starting yield (1-5, x20 %),
#                           hits for the outer and the inner layer, hammer size + % (0-300), hammer meter speed,
#                           hits a medium and a strong blow count for (1-5), points per weak, medium and strong blow
#   102 fill the furnace    powder line in % of the furnace (1-100), good precision %, perfect precision %,
#                           points for good, points for perfect
#   103 heat the furnace    heat to reach, heat lost while not pumping (x0.05 a tick), points for the round (500-50000)
#   104 mold the metal      how much a spill wastes, points per bar poured (500-50000)
#
# The ore round must come first: it sets the ore every later round is colored and measured for.
# The defaults these replace, from Smelting.SmeltingData: hits Copper 1/1, Tin 1/1, Iron 2/1, Silver 2/2, Gold 3/2;
# powder line Copper 65, Tin 70, Iron 75, Silver 80, Gold 85; precision 8 and 3; spill 2.5.
